60-Second Google Sheets Setup Guide
Crucial Setting to Prevent 401 Errors: In Google Apps Script, ensure Who has access is set to "Anyone" (NOT "Only myself"). If left as "Only myself", Google blocks automated submissions with an authorization error.
  1. Open a new Google Sheet at sheets.new
  2. Click Extensions > Apps Script in the top menu.
  3. Paste the script below into Code.gs, replacing existing content.
  4. Click Deploy > New deployment.
  5. Click the gear icon next to "Select type" and choose Web app.
  6. Set Execute as: Me and Who has access: Anyone.
  7. Click Deploy, copy the generated Web App URL, and paste it into the configuration on the left.
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Reference Code", "Timestamp", "Full Name", "Email", "Phone",
        "Organization", "Sector", "Service Area", "Format",
        "Preferred Date", "Time Window", "Message Scope", "Source"
      ]);
      var headerRange = sheet.getRange(1, 1, 1, 13);
      headerRange.setFontWeight("bold");
      headerRange.setBackground("#001f3f");
      headerRange.setFontColor("#ffffff");
    }

    sheet.appendRow([
      data.referenceCode || "",
      data.timestamp || new Date().toISOString(),
      data.fullName || data.name || "",
      data.email || "",
      data.phone || "",
      data.organization || "Not specified",
      data.sector || "General",
      data.serviceArea || data.service || "",
      data.consultationMode || "In-Person (Vision Plaza, Nairobi)",
      data.preferredDate || data.date || "",
      data.preferredTimeWindow || data.time || "",
      data.message || "",
      data.source || "MWA Website"
    ]);

    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      referenceCode: data.referenceCode
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

Method 2: Live Auto-Sync to Excel
Continuous Real-Time

To have new bookings automatically flow into Excel without downloading files every time, use one of these two proven paths:

Path A: Google Sheets → Excel Auto-Sync (Easiest)
  1. In your Google Sheet, click File > Share > Publish to web.
  2. Select Entire Document and change "Web page" to Comma-separated values (.csv), then click Publish.
  3. Copy the published link. In Excel, click Data > From Web and paste that link.
  4. In Excel's Data Connection properties, check "Refresh every 5 minutes".
  5. Result: Whenever a client books on the site, the sheet updates instantly, and your Excel spreadsheet updates itself automatically!
Path B: Direct Excel Web Query (When Production Domain is Live)

Desktop Excel showed "Unable to connect to the remote server" because the development preview domain is protected. Once your website is on your live domain (e.g., https://mwangiandwangonduassociates.com), you can paste:

In Excel: Data > From Web > paste URL > Refresh All.

You never need to give anyone access to your personal email or apps. For your protection, never share account credentials or passwords. The booking form and backend already record, validate, and store every client consultation automatically.
